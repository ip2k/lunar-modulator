S1Sound 1no cables

Make a cable by dragging from an output to an input. While one is in hand every destination opens; jacks that would refuse it turn the refusal colour and say why, and for a per-voice cable the targets marked v stand out.

Without a mouse, the table is the way: N on a source, type-ahead to a destination, Enter. On the map, Enter on an output starts a cable the same way. Screen readers get the table; the map is a picture of it.

Focus (F) keeps the selected module's or destination's cables bright and dims the rest without their labels, so 32 cables stay readable. Cables between modules run in the gutters beside the rack, never across a module.
