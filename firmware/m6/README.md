# M6 audio-path image (FM-1 image built, not run; kit image run)

A RAM-only, SDK-free pi32v2 image for milestone M6 (docs/18): ALNK0 at about
44,118 Hz to the external codec through #176's driver
(`firmware/board/alnk0_audio.c`), one reduced engine voice, per-block timing
in a RAM status block, and on the FM-1 the build id and the timing on the
TFT. Loaded by the mask ROM at `0x01C02000` and jumped to, like M4 and M5.
Details, evidence and the FM-1 approval request:
`notes/2026-11-09-m6-image.md`.

| File | What it is |
| --- | --- |
| `startup.S` | `cli`, the two stacks, `call M6_ENTRY` |
| `app.ld` | the whole ROM upload window, `[0x01C02000, 0x01C07E00)`; the link fails if the SSP stack top passes `0x01C07E00` |
| `m6_core.{h,c}` | the voice, the status block (layout 1, 144 B), the TIMER4 stopwatch, the polled ALNK0 block loop, the timing accounts and the report formatters. Host-tested |
| `m6_sine.h` | generated by `tools/m6_tables.py` (bit-exact to kSinTab12's quarter wave) |
| `m6_screen.{h,c}` | the FM-1 panel: a static frame, then eight status lines redrawn a few bytes per block. Host-tested |
| `main_fm1.c` | the FM-1 entry (`m6.bin`) |
| `main_devkit.c` | the AC79 kit entry (`m6-devkit.bin`): no panel, PA2 or matrix; ALNK0's PORTC pin writes dropped and counted; reports on the M4 debug UART; 40,960 blocks, then the M4 reset back to the kit's application |

The voice: two-operator FM (modulator at twice the carrier, index up to
π/2), a 128-sample linear attack and a slow exponential decay, an A3–C#4–E4–A4
arpeggio at 512 blocks per note, −18 dBFS of Q23, L = R. The PCM hash of the
first 1,024 blocks is `0x92CF0315` on the host and on the kit.

Interrupts stay masked: the loop polls ALNK0's pending flag (CON2 bit 7) and
acknowledges it by writing bit 3. Both entries clear the P33 watchdog every
256 blocks if an application left it armed (SDK `wdt_clear`,
`lunar_ramtest_wdt_kick`).

Build (two runs give the same hashes):

```bash
LUNAR_BUILD_ID=m6-plan-2 LUNAR_SESSION=<label> \
  bash tools/jieli/link-diagnostic.sh <docker-host> <toolchain-dir> <scratch-dir> m6
# -> build/jieli-m6/: m6.bin, m6-devkit.bin, ELF, map, disasm, audit_link.json, report.json, sha256.txt
```

Tests: `tests/test_m6_image.py`, `tests/test_ramtest_image.py` (watchdog
kick), `tests/test_diagnostic_report_ram.py` (the `ram-window` budget).
