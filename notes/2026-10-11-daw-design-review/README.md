# Song workspace design review evidence

This directory preserves the independent browser design review and its
rendered evidence. The reports and `final/` assets are copied unchanged from
the ignored `scratch/daw-design-critic/` source; links between the reports and
the assets remain relative.

`2a2ad121431f6e7fac5aa186d00eb0b75848187441ffe0d4ec4222451ed65cc3`, is
