# Genuine trace return admission composition

This successor test stream exercises actual canonical install, boot, read,
native and returned-admission factories. Device syscalls, clocks, passive USB
captures and owned-process lifecycle files are modeled. It does not run the
capture supervisor, access hardware or establish CPU reset cause, pixels or
recovery after a corrupted application. Parent owns commits, pushes and hardware.

Before implementation, the source-backed distinction was that a stopped ioctl
and consumed pretransport failure are different grammars. The fixture therefore
uses real source-emitted native/outer logs for ioctl exception and nonzero status;
missing and empty command-log cases inject only log filesystem failures after
the reader has created its own consumed marker. No fabricated authority, registry
membership, activation constant or success receipt is used in genuine branches.
