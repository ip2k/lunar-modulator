[verified] Shared external-arena application APIs prepare the cold app and adopt
modulation constructed directly in its final storage. Adoption attaches rendering
and UI glue without rebinding the runtime or resetting saved sound parameter
bases, modules or routes. Live rendering and invalid ownership refuse without
changing application state. Caller must supply a valid staged runtime bound to
its adopted engine catalogue; this API alone is not full PROJECT activation.

[verified] Host campaign passed 106 cases across 30 Hera ASAN/UBSAN chunks,
including 30 cold modulation cases, 30 DX7 cases, 30 scalar cases and 16 existing
arena/audio cases. Valid cases retain module parameters and saved bases and
exercise velocity-to-amplitude routing during finite, nonzero audio rendering.
All shard logs and terminal exit/no-OOM states inspected, source hashes matched.

provenance after the shared app changed. The catalogue was rebuilt from the
immutable current snapshot: all 167 objects passed in 16 compiler shards.

optional Plate and text/binary embedded assets. New adoption entry points remain
rooted; SDK-free audits, embedded bytes and regression checks passed. All owned
containers removed. Failed first-campaign logs retained privately.
