# Ordered demo selection to private target image

The new `tools/native/build_demo_image.py` composes the existing trusted-ID
selector and target builder. Operator-owned codec, compiler and catalogue
paths are CLI arguments, never request fields. The request is limited to
64 KiB and parsed with duplicate-field refusal. Output directories must be
fresh. Failed builds retain diagnostic files without an `image.json` success
receipt.

The controller fixes diagnostic runtime, watermarking, expanded-d9000 link
budget, indexed TFT, twelve Shapes voices and compressed wave tables. It
uses the prepared manifest digest and selected startup index together,
links the production project loader and disarmed SAVE service, and rechecks
prepared input identities after linking. The success receipt binds ordered
project IDs, startup project, module selection, exact packed descriptors,
app/ELF hashes, layout and complete key audits. All physical, playback, RAM
and default admission flags remain false. It does not create a firmware
package, HTTP build daemon, installer route, or device transport.

Validation: 17 controller checks plus five production SAVE-option checks
passed locally with the repository venv. Changed project ordering, startup,
manifest, modules, payload/output digests, audit status, runtime/write policy,
layout/budget and armed SAVE metadata are rejected. The checked-link function
also accepted the actual retained Event Horizon target build on Hera, from
`/home/claude/mvave-fm1/all13-event-showcase-link-v1`; the old receipt predates
the production SAVE metadata, so this check did not require that new field.
It bound ELF `9f0eb06d5bfd0ef5e9553f7db7a97b79064ee1b80bfca9009c1b712ed9378c5b`
and app `3a2ef64e16e69c8d5d3a577c06947167638cd76f5aab5f8e17edfac1cc644d5c`,
865568 bytes. The fresh controller CLI path and new production SAVE option
still need an end-to-end target build; these checks are not that build.

Semantic services retain the primary checkout shared by other work. This
worktree's new files are absent there, so bounded exact file inspection was
used without changing another session's project selection.
