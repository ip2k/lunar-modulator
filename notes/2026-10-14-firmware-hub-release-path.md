# Firmware Hub release path

Its current page requests free firmware with GPL-3.0 source and a GitHub `.fwsc` release, and lists the operator contact as zven@thefirmwarehub.com. It says mirrored packages are taken unchanged from project releases, with source kept alongside. This establishes a published submission route, not listing acceptance or control of the hub origin.

Lunar's release dependency is a verified continuous `.fwsc` plus matching published source/licences, recovery instructions and hardware acceptance. A hub submission should link that exact release and its owner-approved Event Horizon default. The selectable image builder remains a separate Lunar service/UI deliverable; the hub's described mirroring route does not establish custom build integration.

No operator was contacted, release published, domain/service changed, or binary uploaded during this read-only check. User authorization to aim for this site is not evidence that Lunar owns it.
