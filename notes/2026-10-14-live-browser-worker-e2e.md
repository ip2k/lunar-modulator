# Live browser to diagnostic worker E2E (offline/private)

## Result

A real Chromium session loaded the repository's `sim/web/www/installer.html` from a temporary same-origin test service, submitted only after an explicit button click, and received a validated result from the real `DockerJobAdapter` worker. No API request occurred before the click. The selected request had all 13 production engines, all 24 effects, both MIDI modules, all 16 modulation modules, and only Event Horizon (`replacement-showcase-candidate-event-horizon`) selected with `startup_index=0`.

The service returned `POST /api/v1/builds` 202, then a succeeded status. The actual app output was 862,296 bytes, SHA-256 `7175f6d1e97563b07350e0bccb10a9820104eb47a4fc67212797c68651fbd575`, within the diagnostic app budget of 868,836 bytes. The worker's `image.json` binds that same app hash, request SHA-256 `0a3b172639a849aa95d0e97519fc67c2dafc674c17bdde053c48f04be84afe7a`, project and startup index. The API/browser result and artifact receipt both retain `installable=false` and `hardware_tested=false`; the artifact also records `hardware_admitted=false`, `native_ram_verified=false`, `native_playback_verified=false`, and `full_song_default_accepted=false`.

## Limits and next step

This proves the shipped chooser bootstrap, explicit click, same-origin request, real local API path, actual build worker, validated diagnostic response, and UI completion message work together for this test fixture. It does not make the page generally available, establish authenticated deployment, publish/download an installable package, accept Event Horizon as the product default, validate storage behavior, or prove runtime, musical, hardware, USB/MIDI, flash, recovery, or installation acceptance. The default full-song gate remains pending.

Next, coordinator should review this note and privately retained evidence, then decide whether to extend the harness with a controlled chooser edit (for example deselect/reselect) before starting any deployment/authentication work. Public deployment and hardware admission remain separate gates.
