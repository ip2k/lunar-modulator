# Optional target SDK checks in host-native pytest fixtures

Native project/save/workspace/content/sequence fixtures now separate host behavior checks from optional pi32v2 target compilation. Ordinary host CI still executes the host checks; target-only checks skip only when FM1_NATIVE_TOOLCHAIN is absent. A configured path is used unchanged, so a missing compiler or invalid configured SDK fails instead of silently skipping. test_native_content_embedding.py keeps host pack/embed checks unconditional and separately compiles the generated target catalogue across asset counts 0/1/2/4, text/binary inputs, and -Os/-Oz. test_native_project_save_app.py keeps its host SAVE checks and makes only the adapter ABI compile target-dependent.

The target checks cover the production translation units formerly compiled incidentally during host fixture setup, plus the lunar_project_units_t target layout assertion. Helper contract tests verify absent-SDK skip behavior and that a configured-but-missing path is not skipped. Linux/macOS host compile/link flags are in portability ancestor 4263126b.
