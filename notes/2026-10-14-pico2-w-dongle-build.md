[verified] Raw UF2 parsing found the first record is the single RP2350-E10 compatibility block, not an application block: flags 0xa000, payload 256, target 0x10ffff00, absolute family 0xe48bff57, block number 0, declared block count 2. Its extension word at data offset 256 is 0x9957e304 (UF2_EXTENSION_RP2_IGNORE_BLOCK). The remaining 134 records are sequential application payload blocks (block numbers 0–133, count 134), each flags 0x2000, payload 256, family 0xe48bff59, targets 0x10000000 through 0x10008500. The declared count 2 on the workaround block is part of the E10 workaround format; it does not indicate a second workaround record in this file.

[verified] Official format evidence: RP2350 datasheet, §5.1.18 UF2 Targeting / RP2350-E10 erratum, specifies one leading absolute-family block targeting flash end, block number 0 and block count 2; it describes the RP2_IGNORE_BLOCK extension added by picotool 2.1.0: https://datasheets.raspberrypi.com/rp2350/rp2350-datasheet.pdf. Official RP2350 boot ROM source checks the extension flag and ignores records with that extension before passing ordinary records to UF2 processing: https://github.com/raspberrypi/pico-bootrom-rp2350/blob/master/src/nsboot/usb_virtual_disk.c (vd_write_block, source lines 706–719). Pinned SDK 2.1.1 header /opt/pico-sdk/src/common/boot_uf2_headers/include/boot/uf2.h defines ABSOLUTE_FAMILY_ID as 0xe48bff57 and RP2350_ARM_S_FAMILY_ID as 0xe48bff59.

## Late-attaching USB CDC status replay

[verified] On 2026-10-14, updated `dongle/firmware/main.c` to use the pinned Pico SDK USB CDC connection query and replay the banner plus the current DONE/FAULT/FAILED result when a console connects or reconnects while the dongle is idle after an attempt. The check does not touch the PIO state machines, USB_KEY lines, or button/restart path. The startup banner is emitted only if CDC is already connected; a later console connection receives the replay. The public SDK header documents `stdio_usb_connected()` as checking for an active stdio CDC connection: https://github.com/raspberrypi/pico-sdk/blob/2.1.1/src/rp2_common/pico_stdio_usb/include/pico/stdio_usb.h.
