# font5x9.txt -- the virtual FM-1's TFT font: printable ASCII, 5 x 9 cells.
#
# Drawn for this repository (MIT, like the rest of it). Rows 0-6 hold capitals
# and digits, rows 2-6 the x-height, rows 7-8 the descenders. Each glyph is
# "= C" (the character; "= space" for 0x20) and up to nine rows of five
# '#'/'.' cells; missing rows are blank. gen_font.py turns this file into
# src/fm1_font.h; tests/test_sim_web.py checks the two agree.
